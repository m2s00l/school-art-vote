# ATELIER 04 | 중학교 미술 작품 투표 웹앱

React + TypeScript + Vite로 만든 **1단계 프론트엔드 데모**입니다. 깔끔한 온라인 미술관 UI를 우선 구현했습니다.

> **중요: 실서비스가 아닙니다.** 학생 입장은 학번/이름을 입력하는 데모이며 실제 본인 인증이 아닙니다. 관리자 페이지도 누구나 미리보기로 접근할 수 있습니다. 실제 개인정보나 실제 투표 결과를 이 버전으로 수집하지 마세요. Supabase 인증, RLS 정책, 서버 측 투표 검증을 연결하기 전에는 학생들에게 운영용으로 배포하지 마세요.

## 기능

- 4개 주제 전시관 / 작품별 확대 보기 / 개인별 고정 무작위 작품 순서
- 학생 데모 입장(학번, 이름, 별명), 작품 업로드/수정/삭제 (등록 단계)
- 브라우저 Canvas 기반 WebP 압축 (긴 변 최대 1600px, 품질 0.74)
- 구역별 3개까지 선택, 총 12개 선택, 최종 제출(시연용)
- 투표 마감과 결과 공개, 구역별 순위와 자신의 작품 순위
- 관리자 대시보드, 작품 삭제, CSV 형식 명단 입력, 참여 현황·순위 CSV 내보내기
- 모바일, 태블릿, PC 반응형 디자인

## 내 컴퓨터에서 실행

1. [Node.js](https://nodejs.org/) LTS 설치
2. 프로젝트 폴더를 열고 터미널에서 실행

```bash
npm install
npm run dev
```

3. 터미널에 나온 로컬 주소(보통 `http://localhost:5173`)에 접속
4. 관리자 미리보기에서 **운영 단계**를 `작품 등록`으로 바꿔 업로드 시연, `투표 진행`으로 바꿔 투표 시연
5. 학번 예시 `10301`, 이름 `김학생`으로 데모 입장
6. 투표 결과를 보려면 관리자 미리보기에서 운영 단계를 `결과 공개`로 변경

### GitHub에 올리기

GitHub의 새 **Private** 저장소를 만든 뒤 압축을 풀어 파일들을 업로드하세요. `node_modules/`, `.env`를 업로드하지 않습니다.

### Vercel 배포

Vercel → Add New → Project → GitHub 저장소 선택 → Framework Preset: **Vite** → Build Command: `npm run build` → Output Directory: `dist` → Deploy.

**주의:** 현재 인증·접근 통제 없는 데모임을 충분히 인지한 뒤 가상 데이터로만 검토하세요. Vercel Hobby의 이용 조건(개인·비상업적 이용 제한)도 학교 사용 전에 확인해야 합니다.

## 데이터 보관 방식

데모 데이터는 `localStorage`에 보관됩니다. **같은 브라우저**에서만 유지되며, 다른 기기와 공유되지 않습니다. 업로드 작품이 많으면 브라우저 저장 용량을 초과할 수 있습니다. 샘플 작품은 Unsplash의 원격 이미지이므로 인터넷 연결이 필요합니다.

## 2단계: Supabase 연결 전에 반드시 구현할 것

1. **학생 인증:** 학번/이름만으로는 본인 인증 불가. 교사가 일회용 초대 코드/임시 비밀번호를 발급하거나 학교 인증 방식과 연결. 비밀번호는 평문 테이블 저장 금지. Supabase Auth 활용.
2. **관리자 인증:** Supabase Auth + 서버에 정의된 역할로 관리자 권한 검증. 클라이언트의 `isAdmin` 값만으로 허용하지 않기.
3. **RLS 정책:** 작품 수정·삭제는 작성자만, 투표 원장은 본인 것만 읽고 쓰도록 제한. 공개 갤러리/순위는 정책에 따라 최소 데이터만 노출.
4. **Storage 접근 권한:** 작품 이미지의 경로와 소유자 검증. 개인 데이터에 공개 URL 사용 금지. 사용자별 업로드 경로와 서명 URL 등 검토.
5. **서버 원자적 투표 제출:** RPC/DB 함수 및 제약으로 구역별 최대 3개, 전체 12개, 중복·자기투표 금지, 투표 가능 단계 확인. 제출 트랜잭션을 사용해 조작·중복 요청을 막기.
6. **시스템 단계 통제:** 서버에서 업로드 기간·투표 기간·결과 공개 상태를 검증.
7. **중복 학번 및 관리 기능:** 학생 명단은 교사만 등록 가능, 수업 종료 후 보존·삭제 정책 설정.
8. **운영 성능:** Storage에 WebP 업로드, 썸네일 별도 생성, 페이지네이션/지연 로딩, 30명 동시 접속 테스트.
9. **투표 변경 정책 결정:** 지금 데모는 최종 제출 전까지 수정 가능하고, 제출 후에는 수정이 불가능합니다.

## 제작·검증 안내

이 환경에서 npm 레지스트리 설치가 제한되면 자동 빌드 검증이 완료되지 않을 수 있습니다. 로컬 PC에서 `npm install && npm run build`로 확인해 주세요.
