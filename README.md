# 미술 작품 투표 웹앱 v3 (화면 확인용)

## 변경 사항
- 작품 등록: 다섯 섹션 중 원하는 섹션에만 등록할 수 있습니다. 제목과 이미지가 있는 작품 한 개씩 독립적으로 저장됩니다.
- 투표: 각 섹션에서 0~3개 작품을 고를 수 있으며, 총 1~15개를 선택하면 최종 제출할 수 있습니다.
- 작품 이미지 위 오른쪽에 **선택 체크박스**가 표시됩니다. 이미지 자체를 클릭하면 확대됩니다.
- 본인 작품에는 투표할 수 없습니다.
- 관리자 화면에서 **투표 진행** 단계로 전환해야 선택 버튼이 표시됩니다.

## GitHub Pages 배포
- 저장소 최상위에 `src/`, `public/`, `index.html`, `package.json`, `vite.config.ts`, `.github/` 등이 위치하도록 업로드하세요.
- `vite.config.ts`의 base가 `/school-art-vote/`인지 확인하세요.
- `.github/workflows/deploy.yml` 파일을 유지하면 GitHub Actions로 자동 배포됩니다.

## 로컬 빌드
`npm install` 이후 `npm run build`

## 중요
이 프로젝트는 프론트엔드 데모로, 브라우저의 localStorage에만 작품 및 투표 결과가 보관됩니다. 서로 다른 기기 간 공유 및 실명 계정 인증이 되지 않습니다. 실제 수업 운영 전에 Supabase 연동, 권한 및 서버 검증이 필요합니다.
